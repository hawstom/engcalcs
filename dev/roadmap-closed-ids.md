# Closed-task ID ledger

One line per closed task, newest first. **This is an index, not a record** — it exists so that a
`Task N` cited from code or from a `dev/` doc still resolves to something, and so
`roadmap_id_check.php` can prove an ID is used once.

The full text of every closed task is in git and nowhere else, by Tom's ruling of 2026-08-16:
`git show 5083c95^:dev/roadmap-closed-archive.md` for the summaries, and
`git log -p -- dev/roadmap-closed-archive.md` for the original narratives behind them.

Durable policy from these tasks lives in `CLAUDE.md` and in `dev/*.md`. Those are the current
state; this is only a list of numbers that were once used.
