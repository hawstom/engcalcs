# Technical-English audit of lib/lang.ec.en.php (2026-10-07)

Copyright 2009 Thomas Gail Haws. GNU GPL v3 or later.

Tom, 2026-10-07: *"audit the entire lang.ec.en for AI-isms that don't sound like any FHWA, HEC, EPA, or other technical manual ever written."* The house style this audit applies is in `dev/language-strings.md`, section "House style: standard professional civil-engineering technical English".

**Scanned:** all 2,371 `$ec_lang` values in `lib/lang.ec.en.php`. **Findings:** 192 rows: 151 CLEAR (applied to the English file on branch `chore/technical-english`), 41 ASK (not applied). The 26 translations were not touched; they go stale until a sprint, as expected.

- **CLEAR** keeps the meaning and changes only the register. Applied, and the matching JS fallback literals were updated so `js_fallback_string_check.php` stays at zero.
- **ASK** is either a string Tom has ruled on (`dev/english-key-rulings.json` holds his approval of the exact current text; reason begins "ruled"), or a change that moves meaning or tone. Not applied.
- Where a row shows "..." the change is to an excerpt of a longer value; the rest of the value is unchanged.
- Not audited as AI-isms: the author's mission voice (`template_welcome`, the Mission section of `about_body_html`, terms section 2). That is Tom's own writing, not machine register.
