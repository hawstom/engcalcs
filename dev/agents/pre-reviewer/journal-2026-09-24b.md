OBSERVED (worktree `~/webdev/worktrees/feat-first-project/engcalcs`, commit `8bfe1454`; port 8112

  run. The one FAIL — "Attach, from Project1, now paints the world map: 0 tiles" — I chased rather
  than took on faith. Raising the settle delay from 900ms to 3000ms after the Attach click made it
  pass 3/3. I then ran the pass's own pre-existing `specs/basemap.js` **on master** (not this
  branch) and got the identical class of failure ("a new geographic project draws tiles: 0

  known-flaky assertion for evidence against R-208.
