Quick start:
Engcalcs has no MVC model. Each calculator joins (bootstraps) the application by defining the BASE_DIRECTORY constant and then including lib/base.inc.php.

New developers need to add their server name to lib/config.inc.php so that URLs work in the refs and menus and to turn on DEBUG_MODE.
